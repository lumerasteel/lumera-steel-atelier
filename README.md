# آتلیه — حساب‌داری

نسخه‌ی آماده‌ی انتشار در GitHub Pages.

## فایل‌ها
- `index.html` — برنامه
- `sw.js` — Service Worker با cache version جدید `atelier-v14`
- `manifest.webmanifest` — تنظیمات نصب PWA که توسط `index.html` فراخوانی می‌شود
- `apple-touch-icon.png` و `icon-*.png` — آیکن‌ها
- `manifest.json` — نسخه‌ی سازگار/قدیمی از manifest
- `.nojekyll` — جلوگیری از پردازش Jekyll در GitHub Pages

## انتشار
محتویات این پوشه را در ریشه‌ی مخزن قرار دهید و فایل‌های هم‌نام قبلی را جایگزین کنید. این بسته از فایل‌های مخزن دریافت‌شده و نسخه‌ی فعلی `index.html` ساخته شده است.
