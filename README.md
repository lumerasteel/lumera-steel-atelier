# حساب‌داری آتلیه (Prestige Studio)

برنامه حساب‌داری، فاکتور، قرارداد و مدیریت آفیش برای آتلیه عکاسی و فیلم‌برداری (فارسی/راست‌چین، مناسب گوشی، آیفون، اندروید و کامپیوتر).

© تمامی حقوق این برنامه محفوظ است — طراحی و توسعه: فرشاد شهرت — ۰۹۱۴۲۰۳۰۹۰۴

- هنگام اولین ورود، کاربر رمز ورود خودش را می‌سازد و یک «کد بازیابی» می‌گیرد؛ اطلاعات با آن رمز روی همان دستگاه رمزگذاری می‌شود. اگر رمز فراموش شود، با کد بازیابی و بدون پاک شدن اطلاعات رمز جدید گذاشته می‌شود.
- ورود با اثر انگشت یا تشخیص چهره (اختیاری، در صورت پشتیبانی گوشی).
- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند، نه روی GitHub. از بخش «تنظیمات ← بک‌آپ» به‌طور منظم فایل پشتیبان بگیرید؛ فایل بک‌آپ رمزگذاری نشده است.
- نصب: آدرس GitHub Pages را در Chrome (اندروید) یا Safari (آیفون: Share ← Add to Home Screen) باز کنید.

## فایل‌ها
- `index.html` — خود برنامه
- `manifest.json` و `icon-*.png` — نصب به‌عنوان برنامه (PWA)
- `sw.js` — باز شدن بدون اینترنت
- `.nojekyll` — جلوگیری از پردازش جکیل در GitHub Pages
