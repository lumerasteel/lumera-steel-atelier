# حساب‌داری آتلیه

برنامه حساب‌داری و فاکتور برای آتلیه عکاسی و فیلم‌برداری (فارسی/راست‌چین، مناسب گوشی).

© تمامی حقوق این برنامه محفوظ است — طراحی و توسعه: مهندس فرشاد

- هنگام اولین ورود، کاربر رمز ورود خودش را می‌سازد؛ اطلاعات با آن رمز روی همان دستگاه رمزگذاری می‌شود.
- ورود با رمز، و در صورت پشتیبانی گوشی، با اثر انگشت یا تشخیص چهره (اختیاری).
- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند، نه روی GitHub.
- فایل بک‌آپ رمزگذاری نشده است؛ آن را جای امن نگه دارید.

## فایل‌ها
- `index.html` — خود برنامه
- `manifest.json` و `icon-*.png` — نصب به‌عنوان برنامه (PWA)
- `sw.js` — باز شدن بدون اینترنت
- `.nojekyll` — جلوگیری از پردازش جکیل در GitHub Pages
