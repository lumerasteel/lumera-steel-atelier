# آتلیه — حساب‌داری

سورس برنامه همراه با آیکن‌های برند و تنظیمات PWA.

## فایل‌های انتشار
- `index.html` — برنامه؛ favicon به `icon-192.png` متصل شده است.
- `manifest.webmanifest` — تنظیمات نصب PWA.
- `manifest.json` — نسخه سازگار.
- `apple-touch-icon.png` و `icon-*.png` — آیکن‌ها.
- `.nojekyll` — جلوگیری از پردازش Jekyll در GitHub Pages.
- `sw.js` — کش پوستهٔ برنامه برای اجرای آفلاین و به‌روزرسانی نسخهٔ نصب‌شده؛ نسخهٔ کش فعلی `v15` است.

## نکته مهم
فایل `sw.js` در این بسته تکمیل شده است. آن را در کنار `index.html` و فایل manifest در ریشهٔ مخزن GitHub قرار دهید. این Service Worker پوستهٔ برنامه و آیکن‌ها را کش می‌کند، در زمان اتصال نسخهٔ تازهٔ صفحه را ترجیح می‌دهد و کش نسخه‌های قبلی خودش را پاک می‌کند. کش آفلاین تضمین‌کنندهٔ عملکرد آفلاین سرویس‌ها یا APIهای بیرونی نیست.

فایل‌های HTML آزمایشی/مرجع در `design-references/` نگهداری شده‌اند و جزو مسیر اجرای برنامه نیستند.

## اصلاحات سازگاری با iPhone
- صفحهٔ ورود و تعریف رمز در نمایشگرهای کوتاه قابل پیمایش است و فضای امن بالای/پایین نمایشگر را رعایت می‌کند.
- برچسب‌های نوار ناوبری پایین در اندازه‌های کوچک مخفی یا بریده نمی‌شوند.
- درخواست Face ID / Touch ID فقط پس از لمس دکمه اجرا می‌شود تا محدودیت درخواست WebAuthn بدون تعامل مستقیم کاربر در iOS باعث شکست ورود خودکار نشود.
- حذف برنامهٔ وب نصب‌شده از صفحهٔ اصلی، کنترل سیستمی iOS است: روی آیکن نگه دارید و گزینهٔ Remove Bookmark / Delete Bookmark را انتخاب کنید. حذف از داخل Safari یا Chrome قابل اجرا نیست.
