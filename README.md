# حساب‌داری آتلیه

برنامه حساب‌داری و فاکتور برای آتلیه عکاسی و فیلم‌برداری (تک‌فایل HTML، فارسی/راست‌چین، مناسب گوشی).

- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند (localStorage)، نه روی GitHub و نه روی هیچ سروری.
- حتماً از بخش «بک‌آپ» برنامه به‌طور منظم فایل پشتیبان بگیرید.
- برای استفاده: آدرس GitHub Pages این مخزن را در مرورگر باز کنید و «افزودن به صفحه اصلی» بزنید.

## فایل‌ها
- `index.html` — خود برنامه
- `sw.js` — برای باز شدن بدون اینترنت (اختیاری)
- `.nojekyll` — جلوگیری از پردازش جکیل در GitHub Pages
