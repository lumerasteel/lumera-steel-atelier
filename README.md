# حساب‌داری آتلیه

برنامه حساب‌داری و فاکتور برای آتلیه عکاسی و فیلم‌برداری (فارسی/راست‌چین، مناسب گوشی).

- داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند (localStorage)، نه روی GitHub.
- حتماً از بخش «بک‌آپ» برنامه به‌طور منظم فایل پشتیبان بگیرید.
- برای استفاده: آدرس GitHub Pages این مخزن را در Chrome باز کنید و Install app / افزودن به صفحه اصلی را بزنید.

## فایل‌ها
- `index.html` — خود برنامه
- `manifest.json` و `icon-*.png` — مشخصات و آیکن نصب به‌عنوان برنامه (PWA)
- `sw.js` — باز شدن بدون اینترنت
- `.nojekyll` — جلوگیری از پردازش جکیل در GitHub Pages
