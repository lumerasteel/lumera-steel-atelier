فایل‌های برنامه‌ی حساب‌داری آتلیه
================================
index.html              خود برنامه
manifest.webmanifest    تنظیمات نصب (PWA)
sw.js                   حالت آفلاین
icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png   آیکن‌ها

نکته‌ها:
1) همه‌ی فایل‌ها باید کنار هم، در یک پوشه، روی یک هاست با HTTPS آپلود شوند.
2) ورود با Face ID / Touch ID فقط روی HTTPS و در Safari (یا برنامه‌ی نصب‌شده از Safari) کار می‌کند.
3) بعد از هر تغییر در index.html، عدد VERSION در sw.js را بالا ببرید.

ثبت خطا و پشتیبان‌گیری Google Drive
-----------------------------------
- در تنظیمات، گزارش خطاهای JavaScript و Promise در همان مرورگر نگهداری می‌شود (حداکثر ۱۰۰ مورد اخیر). گزارش را می‌توان به JSON دانلود کرد؛ اطلاعات فرم‌ها، رمزها و داده‌های مالی در گزارش وارد نمی‌شوند.
- برای Google Drive باید در Google Cloud Console یک OAuth 2.0 Client ID از نوع Web application بسازید، Google Drive API را فعال کنید و دامنه‌ی HTTPS برنامه را در Authorized JavaScript origins ثبت کنید. سپس Gmail مدیر و Client ID را در تنظیمات وارد کنید و اتصال را تأیید کنید.
- وارد کردن Gmail به‌تنهایی اجازه‌ی دسترسی به Drive نمی‌دهد؛ تأیید هویت Google الزامی است. برنامه فقط مجوز drive.file می‌گیرد و فایل‌هایی را که خودش ساخته فهرست می‌کند.
- فایل بک‌آپ قبل از ارسال با AES-GCM-256 و کلید مشتق‌شده با PBKDF2-SHA256 (۲۵۰٬۰۰۰ تکرار) رمزگذاری می‌شود. رمز بک‌آپ در Drive یا تنظیمات ذخیره نمی‌شود؛ آن را در جای امن نگه دارید.
- برای بازیابی، در تنظیمات «بازیابی از بک‌آپ‌های Drive» را بزنید، فایل را انتخاب کنید و رمز بک‌آپ را وارد کنید. برنامه اعتبارسنجی و تأیید جایگزینی را اجرا می‌کند.
- اتصال Google باید پس از بارگذاری مجدد/انقضای توکن دوباره تأیید شود. OAuth Client ID باید در دامنه‌ی واقعی و HTTPS تنظیم شده باشد؛ فایل محلی (file://) برای OAuth مناسب نیست.
- این قابلیت در این بسته از نظر کد و ساختار اضافه شده است، اما اتصال واقعی به Google Drive نیازمند Client ID و آزمون با حساب Google مالک برنامه است.
